# 📝 Todo App

A simple Todo List application built using **React.js**.

## ✨ Features

* Add new tasks
* Edit tasks
* Display todo list
* Simple and responsive UI

## 🛠️ Technologies

* React.js
* JavaScript
* Vite
* CSS

## 🚀 Run Locally

```bash
npm install
npm run dev
```
